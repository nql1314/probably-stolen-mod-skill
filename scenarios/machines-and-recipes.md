# 场景：自定义机器、配方与加工

适用：注册可摆放机器，增加电池/材料/产物槽，执行即时或跨夜加工，或给已有机器增加升级与液体处理。

## 内容与运行逻辑分开

定义机器物品 ID、模板、槽位类别、容量/功耗、配方输入、输出、时间、解锁条件和图像。先把本次规格中的加工次数、固定产量、质量、效率和性能用途分开，检查实际运行路径、配方文件、检查工程与手册是否一致；最新修正要替换旧规则，保留的兼容字段不能继续驱动已经取消的行为。

已有 Forge 时，通过 `ForgeMachineRegistrationApi` 声明模板与配方，复用框架的槽位适配和资源事务，见 [Forge 接入](forge-integration.md)。原版机器的特殊投料、配方优先级和调度由内容方维护，适合时复用 `ForgeMachineRuntimeApi.CreateBatchProcessor`；不要给同一台机器再叠一套重复结算。其他声明式运行时按其 schema 接入。资源和引用 ID 在注册阶段统一校验。

## 创建机器

1. Forge 模板在目录初始化前提交声明；直接写游戏目录时按原生目录就绪点注册独立工厂。基于当前构建已验证的模板创建实例，建立内部槽、窗口、回调和可保存标签，检查形状、所有权、模块/电池限制。
2. 若窗口会在读档时重建，恢复槽和按钮绑定；避免旧 Unity 引用被继续使用。自定义窗口可参考 [界面注入示例](ui-injection.md)。
3. 把机器状态按“物品实例”保存，不能只按机器类型 ID 缓存。升级上限、耐久、进度和容量统一使用明确单位。

## 配方与投料准入

输入槽的准入来自当前已注册配方的输入与辅助材料，并保留真实品质、纯度、所有权等条件；不能维护一份与配方脱节的固定物品白名单。追加配方经目标机器的公共入口注册，之后同时核对配方快照、准入索引和实际候选槽路由。配方能够计算而材料拖不进去，要查完整准入链，见 [拖放排查](item-interactions.md)。

同一物品 ID 不保证满足真实条件。正品、可用性或纯度要求从原生状态读取，不根据名称、图标、伪装标记或 tooltip 推断。注册和更新时完成整组校验并发布完整配置；输入、输出和液体列表不在运行中被调用者直接改写。机器实例、可选依赖或追加配方未就绪时，只关闭受影响的能力并给出定位信息。

## 一次加工的执行顺序

先只读检查机器仍存在、配方解锁、材料数量、目标容量、电量/燃料、输出落点。按机器当前原生电耗预检和扣电；属于机器耗电的逻辑不另写配方固定电费，也不重复计算原生已经应用的效率。若玩法确有独立能源费用，单独声明其单位与规则。

确定全部可满足后再执行消耗与产出，并逐步核对实际返回值；游戏 API 无事务时准备失败补偿或可重试的待交付记录。预检与写入之间若库存或机器状态变化，就废弃旧计划。跨夜加工先观察真实调用顺序，选能让完整结果进入本次存档的合法结算点，按“存档槽 + 周目 + 过夜转换 + 机器实例”去重；跨越日计数改变的两个回调必须映射到同一转换。

当前 Forge 夜间模板按每台每夜最多尝试一批处理，接入时复核现用版本契约。用户要求“每晚只处理一次”时，性能不得增加批次数，失败恢复也不能变成额外生产。固定配方与生物配方按声明数量产出；质量用于纯度或品级时只改相应属性，不复制产物。其他玩法的属性用途按其明确规格实现，不从属性名自行推导。

动作通知未必表示成功生产。只有材料、能源、输出和原生工作资格都证实本批完成，才触发一次工作效果；跳过、失败、重入和读档恢复不得重发。机器按实例分别记录本晚已检查、已提交或待恢复；正常的部分加工进度与失败恢复态应分开。

液体处理要先确认原生体积单位、质量分类和混合组成，再写清 ml/L 转换、来源所有权、过滤前后污染量和滤芯耐久；不能用评分或 UI 文案猜测原生可用性。失败补偿须恢复实际组成和体积，不能以等量的另一种液体代替。机器升级的材料消费遵循 [交互示例](item-interactions.md)。

## 扩展原版加工

优先保留原版配方、排序与属性处理。原版已经提升纯度或应用某个效果时，不再追加同样的增益；内容方新产物的品级按明确的独立规则处理。

需要在原版过夜处理前完成扩展批次时，核对 `PlayerStore.EndNight` 的真实边界、原版是否仍会再次处理同批材料，以及本次保存顺序。通过当前构建的 `FindAllItem` 或已有公共观察接口发现实际放置的机器，核对嵌套位置和所有权。确需抑制原生子回调时，只针对已由扩展接管的机器/配方安装精确钩子，并保留原版其它配方；不把某次构建的生成方法编号当稳定契约。

## 验证

先检查配方、准入、单位、固定产量、属性用途和失败恢复规则，再按本次原生测试范围检查新建、摆放、追加配方投料、加工、断电、材料不足、产物槽满、保存重载及跨夜重复回调。分别读回材料、输出、能源、机器进度和工作效果；满输出或其它预检失败时，材料与能源不应已被消耗。对液体核对组成及恢复，对原版扩展检查原生配方和纯度效果仍正常。纯规则检查与配方可解析不能证明存档闭环。
