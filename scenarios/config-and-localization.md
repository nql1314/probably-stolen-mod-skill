# 场景：设置、数据文件与本地化

适用：可调数值、热键、目录型内容数据、多语言名称/说明。设置只有进入实际行为计算或 UI 路径才算生效。

## MelonPreferences

为设置提供安全默认值与有效范围；读取后将概率、倍率、尺寸、周期和数量分别校验。旧键迁移应保留用户已有合法值，迁移成功后再写新键。热键要排除游戏窗口失焦和不相关界面，动作型热键用按下沿。

## 自定义数据文件

解析前确定格式版本、编码、允许的字段及最大文件/条目数。逐条校验稳定 ID、引用 ID、数值范围、必填资源与重复项；错误日志包含文件及条目位置。不要将前半部分有效、后半部分失效的数据静默发布为完整内容。跨文件引用需要统一验证后再注册。

## 本地化

优先沿用游戏或项目现成的本地化键路径。新增物品、Perk、角色或按钮至少准备默认语言的名称与说明；缺语言键时显示可读回退，不显示内部 ID。动态 tooltip 使用实际状态和单位生成，切换语言或内容刷新后重新渲染。

## 验证

默认配置、合法自定义值、越界值、旧配置迁移、缺失资源、不同语言各检查一次；日志能定位无效项。确认修改配置后游戏内结果也变化，不能只看到设置面板变了。
