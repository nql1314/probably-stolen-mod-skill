# 场景：添加自定义开局

适用：新增一套可选初始条件，包括起始物品、现金、租金、升级、声望或允许的开局类型。若只是选择一个开局 Perk，使用 [Perk 示例](starting-perks.md)。

## 定义与校验

用带命名空间的 ID 和格式版本描述开局；列出允许的原生开局类型、点数或费用、物品增删、状态增减及本地化文案。加载数据时校验 ID 唯一、数字范围、物品引用存在、互斥关系和配置版本。不要把反编译时观察到的枚举整数当成跨版本稳定 API。

## 应用时机

1. 在主菜单/开局选择列表就绪后显示选项，但此时不修改玩家状态。
2. 在游戏新局初始化完成、玩家与库存可用后应用开局内容。先核对当前存档槽与周目身份，记录尚未执行、部分完成、已完成三类状态；只在已实际放入物品/写入状态后标记完成。
3. 移除物品先核对所有权与数量；新增物品使用当前目录创建，并走游戏接受条件。现金、声望和升级调用当前构建的游戏方法，再读取结果确认。
4. 读档只恢复状态，不再次应用一次性开局内容；切换存档槽或新建周目时重置对应缓存。若依赖异步初始化，使用有限重试且避免一帧多次发放。

## 验证

新局选择后检查每项变化；库存不足、满格或引用缺失时检查部分完成和重试；保存重载与另一存档槽不重复发放。若必须读取原生字段偏移，记录当前构建特征并单独做运行验证。
